# 💻 Scholarship Consultant System (C++)

A simple and interactive terminal-based system built in C++ to help international students evaluate their scholarship eligibility. The system processes student inputs and guides them through different scholarship tiers.

## 🌟 Key Features

* **Scholarship Tier Evaluation:** Uses clear conditional flow (`if-else` structures) to evaluate eligibility for Bachelor, Master, and PhD scholarships.
* **Basic Input Validation:** Ensures that user entries conform to the required criteria before processing.
* **Document Readiness Checklist:** A step-by-step interactive terminal checklist to verify if the student has essential documents (Transcripts, Letters, etc.).
* **Country Advisory Logic:** Built-in logic to provide basic recommendations and pathways for different destination countries based on user profiles.

## 🛠️ Technical Stack
* **Language:** C++
* **Core Concepts:** Input/Output Streams (`cin`, `cout`), `if-else` conditional statements, Loops, and Functions.
